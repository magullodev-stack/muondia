# Instrucciones para IA y colaboradores

- La sincronización con GitHub es automática: `scripts/sync_main.ps1 -Watch` arranca al abrir la carpeta en VS Code y hace commit, rebase y push a `main`. No pidas al usuario `git pull` ni `git push` a mano.
- Varias IA modifican este repo. Antes de diagnosticar o editar, comprueba que tienes la última versión de `main`.
